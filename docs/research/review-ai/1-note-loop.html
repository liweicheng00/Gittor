Wireframe 1 · The note loop in the Review window

Each note has a state: Open → Sent → Answered (the agent replied, with a commit) → Resolved. "Send to Agent" makes one task text from the open notes and marks them as Sent. The agent writes its reply into the note through the gittor-bridge CLI or the local MCP server. The human checks the change and clicks Accept or Reopen.
