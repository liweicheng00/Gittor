Wireframe 3 · The agent bridge: notes in, replies out, no ref writes

Left: the Worktrees tab shows which agent session works in which worktree, its state, and the open notes of the review of its branch. Right: Settings › Agents. Gittor gives a CLI and a local MCP server over stdio. The agent starts the server as a child process, so no port is open. The tools can read the review and write replies and suggestions. They cannot move refs, merge or push.

The bridge has no command for these. LogEach write of the bridge goes to .git/gittor/bridge.log and shows in Local History.
Tools of the MCP server (the same as the CLI subcommands)
review_list() → the reviews of the repository
review_start(branch?, base?, title?, summary?) → a new review, or a new round (wireframe 4)
review_get(branch) → files, commits, notes with state, path:line and code around the line
review_task(branch, state="sent") → one Markdown task, as "Send to Agent" makes it
note_reply(branch, id, text, commit?) → the note becomes Answered
note_suggest(branch, path, line, end_line, text, severity) → a suggestion, not a note yet
local_notes_get(path?) → the notes on uncommitted changes of this worktree
