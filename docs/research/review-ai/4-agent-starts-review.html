Wireframe 4 · The agent starts a review with the CLI

When the agent finishes a task in its worktree, it runs gittor-bridge review start. Gittor makes the review (or a new round of it), keeps the summary of the agent, and shows a toast. A second run on the same branch adds round 2. It does not change the base, and it does not make a second review. The rounds give the "changes since round 1" diff of wireframe 2.
