Make the window as narrow as 320 px, and keep the commits of a submodule on Update.

## Improved
- The window can now be as narrow as 320 px, so Gittor fits as a side panel. In a narrow window, a project tab shows the folder name only.

## Fixed
- Update Submodules no longer loses the commits of a submodule that are on no branch. It skips that submodule and tells you to create a branch there first.
- In the file list of Compare, the note count and the status of a file stay on the line of the file name.
- Two security advisories of the libraries of the app are fixed.
