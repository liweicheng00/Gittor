Press Shift twice to find a file by its name, and edit your notes in place.

## New
- Go to File: press Shift twice, or Ctrl+Shift+O, and type a part of a file name. Enter opens the file in the center panel.
- Edit a note with its edit button, or with a double click on its text. Ctrl+Enter saves the new text.
- Drag the header of a changelist onto another changelist to move all its files. A drop anywhere in a changelist counts.

## Improved
- The Files tab and the file list of Compare show the count of the open notes of each file and folder.
- Copy All Notes is now in the Compare window and in the Review window. In Review, it copies the notes of all files of the review.
