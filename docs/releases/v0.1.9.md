Open in Editor opens the file in its project, and the left tabs are easier to read.

## Improved
- F4 opens the file in the folder of the repository, not alone. Zed, VS Code, Cursor, Windsurf, Sublime Text and the JetBrains IDEs show the file in that project.
- The active left tab is a filled block with a colored icon, and the tab bar stands apart from the toolbar. The Files tab shows a folder icon.
- The counts of the left tabs show as small badges on the corner of their icons.
- In the Recent list of the Open menu, the worktrees of a project have a clear indent.

## Fixed
- With Xcode, F4 and the IDE button open the file at the correct line.
