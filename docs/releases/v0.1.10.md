Copy works everywhere with Ctrl+C, and Cherry-Pick without Commit is in the menu of a commit.

## New
- Cherry-Pick without Commit in the menu of a commit puts its changes in the Changes tab, without a commit. Undo puts your files back as they were.

## Improved
- You can select text with the mouse and copy it with Ctrl+C in all parts of the app. A text selection always wins over other uses of Ctrl+C.
- Ctrl+C on a file copies its absolute path, and on several files one path for each line. Copy Path in the menus also gives the absolute path, and Copy Relative Path is new.
- The keys of the left tabs follow their order: Ctrl+1 to Ctrl+5 for Branches, Changes, Worktrees, Stash and Reviews. Ctrl+6 shows the submodules.
- A Markdown file of the Files tab shows its preview in one column.
- The card of an update has a link to the full release notes of the new version.

## Fixed
- Annotate works for a file of the Files tab, and a failed Annotate no longer repeats its message.
- With a new note open, Ctrl+C copies the selected lines of the editor.
