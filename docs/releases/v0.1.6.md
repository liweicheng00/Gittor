A Files tab, drag and drop with a check before the run in Interactively Rebase, and a screen that no longer flickers.

## New
- The Files tab shows the files of the working tree in their folders. It is the first tab on the left, and Ctrl+` opens it. A click shows the diff of a changed file, or the text of another file.
- In the window of Interactively Rebase from Here, drag a commit to change the order, or drop it on another commit to squash it. Hold Alt for a fixup.
- Before the run, that window checks each step for conflicts and empty commits, and warns about pushed commits. Nothing changes until you click Run Rebase.
- Copy for an Agent in that window copies the plan and the check as a task for a coding agent.
- Ctrl+E opens the repository in the editor, with the selected file or the file of the diff.
- While you hold Alt, each project tab shows its number for Alt+1 to Alt+9.

## Improved
- The screen no longer flickers when other programs change files. The lists, the log and the diff keep their place, and a reload waits while you use the mouse.
- Alt+` switches to the next project, and Alt+Shift+` to the one before.

## Fixed
- A second Ctrl+1 no longer hides the left panel. View › Left Panel hides it.
