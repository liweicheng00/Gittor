Create a branch with Ctrl+B, and write notes on your local changes in Compare.

## New
- Ctrl+B opens New Branch. The From field starts at the current branch, and the branch picker can choose another one.

## Improved
- Notes on local changes are now in Compare. A double click on a file in the Changes tab opens it. The diff panel under the Changes tab has no notes.
- Update also fetches the default branch of the remote, for example origin/main. Your local main does not change.
- The welcome screen has no toolbar and no status bar. A Settings link is under its buttons.

## Fixed
- On macOS, Restart after an update brings the new window to the front. This applies from the next update on.
- In a low window, the top of the welcome screen is no longer cut off.
